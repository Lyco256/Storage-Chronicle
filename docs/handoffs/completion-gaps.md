1. On a disposable Windows 11 acceptance host, run the complete privileged capability matrix and TestLab workloads. Preserve executed and explicitly blocked capabilities.
2. On Windows 10 22H2, run the compatibility matrix covering capability detection, service, Avalonia, NTFS/USN/MFT, ETW, Clipboard, SMB/Share, cloud placeholder, removable media, and installer behavior.
3. Run the Agent and Session Agent through the supervised 600-second resource gate with independent final-five-minute quiet evidence; run the dedicated labeled MFT 10K/100K/1M matrix.
4. Run live Agent/Explorer correlation and physical Windows 10/11 installer acceptance, retaining deterministic fixtures only as supplemental evidence.
5. Fix every measured failure without weakening record quality, then rerun Fast, quality/coverage, UI, privileged, resource, benchmark, installer, correlation, and documentation gates.
6. Only after all verification rows have executable evidence, merge the reviewed feature into `devenv` with `--no-ff`; rerun final integrated gates; then merge `devenv` into `main` with `--no-ff`.

No file contents or content hashes; no history-deletion behavior; no synthetic descendant events for directory operations; no fake data standing in for missing acceptance; no duplicate shared contracts; no unapproved changes under `Requirements/`; no merge from a dirty or unreviewed worktree; and no default test result that hides an unexecuted privileged lane.
