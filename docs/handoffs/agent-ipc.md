## Top-agent integration: Activity Frame service contract

`DiffProjectionResponse` now carries a separately paged optional Activity Frame summary list; selected-frame canonical events use the independent `DiffActivityFrameTimelineRequest/Response`. Agent summaries come from the canonical log through `ActivityGrouper`, use the persisted `PaneTimeoutSeconds` (5-second product default when no settings store is supplied), and are exposed for Live/Replay only. Summary sort direction is explicit in the backwards-compatible request and applied before paging, so newest-first remains correct even when the history exceeds one page. Each event detail contains event id/time/path/operation/quality only, never contents or content hashes. Page size is validated and bounded; malformed ranges, missing frame IDs, and cancellation remain explicit.

Top-agent follow-up adds `IProcessLifecycleSink` as a platform-neutral boundary. Windows ETW ProcessStop is matched only to the cached Process Instance ID and queued into a bounded background writer, so the ETW callback never waits for disk I/O. The writer flushes a distinct exact non-file `ProcessLifecycleEvent` to the authoritative segment before publishing its SQLite row; AgentWorker stops collectors, drains the lifecycle writer, then stops storage. Queue saturation and persistence failure are surfaced through the collector/Agent health path; after a storage failure, Health explicitly reports how many queued tail facts were not attempted, and those facts are not retried. It is never appended as a source/canonical file event. Replay selects durable lifecycle facts for candidate process instances and UTC range; after Agent restart it can restore observed process-exit boundaries. Missing/unknown PID mapping is ignored, not guessed. Startup/index rebuild recovers lifecycle rows if the SQLite projection index is missing or corrupt. Agent tests cover graceful drain-before-storage-stop and unattempted-tail reporting.
