# Initialize-TestLab.ps1

Validates the user-approved TestLab config in read-only mode by default. `-Target Windows11` requires only the Windows 11 ISO; `-Target Windows10` requires only the Windows 10 22H2 ISO; `-Target Both` requires both. With explicit `-Apply`, it creates or validates only `SC-Test-W11-VBox`/`SC-Test-W10-VBox` VirtualBox VMs under the approved root, with exactly 2 vCPUs, 4096 MiB RAM, dynamic 80/64 GiB VDI, EFI (and Windows 11 TPM2), disabled 3D/audio/USB/clipboard/drag-and-drop, and NAT only while provisioning. It verifies every existing VM disk remains under the approved root and attaches only the supplied local official ISO paths.

The script never installs VirtualBox, reboots, changes BIOS/UEFI, downloads media, installs the guest OS, creates a baseline snapshot, or touches a host physical volume. The manifest records that Guest Additions, guest installation, network disconnection, and exactly one `SC-CLEAN-BASELINE` snapshot remain user actions. Failure is fail-closed and written under `artifacts/acceptance/testlab/<run>`.
