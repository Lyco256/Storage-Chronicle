# Verify-Windows10PhysicalAcceptance.ps1

Read-only fail-closed Windows 10 22H2 host preflight. It requires explicit BundleRoot, marked TestDataRoot, and pre-existing user-approved EvidenceRoot. It verifies local non-reparse paths, separation from system/program/repository/bundle/synced roots, x64/22H2/admin status, physical-model heuristic, dedicated fixed NTFS volume identity and role, 40 GiB free space, exact run markers and otherwise-empty fixture root, absence of existing Storage Chronicle install/history/service, and relevant SMB-share conflicts. Uninstall registry keys are enumerated without suppressing errors for machine scope and every loaded non-special user profile; any non-special profile hive that is unloaded is reported as uninspectable and fails closed. Per-user install paths and existing product/history paths are checked for reparse ancestors. SMB collision checks include the `SCAcc` names generated by the privileged integration tests and exact path-boundary overlap with TestDataRoot. Query failures are FAIL, never assumed safe. It records computer name, volume identity, run GUID and check details, then writes one new create-only JSON report in EvidenceRoot (`AcceptanceEligible=false`); existing reports are never overwritten. `Ready=false` exits 2. A passing model heuristic is not hardware attestation and does not replace the current-commit source audit or independent runtime write monitor. The script never starts the product, installer, privileged runner, service, VHDX, or workload.

Tests: PowerShell parser validation; static contract tests require create-only output, non-reparse/local path checks, volume/role identity, existing installation/history/service/share checks, and fail-closed behavior.
