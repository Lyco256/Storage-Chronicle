# Finalize-Windows10PhysicalAcceptance.ps1

Composes the final `StorageChronicle.Windows10PhysicalAcceptance.v1` artifact only after validating three independent real-evidence inputs: a passed Release Windows privileged capability matrix captured on an elevated Windows 10 22H2 x64 physical host, the `StorageChronicle.Windows10PhysicalPreflight.v1` output from `Verify-Windows10PhysicalAcceptance.ps1` (the exact unique `windows10-preflight-<guid>.json` created beneath the approved EvidenceRoot), and the physical-machine installer manifest with all eleven cases passed. It does not run an installer, change a machine, or infer a pass from the installer script's separate `RealMachineInstallerPreflight` artifact. Missing, malformed, diagnostic, nonphysical, or ineligible inputs produce a `NOT_EXECUTED` manifest and exit code 2.

The privileged manifest must use `StorageChronicle.WindowsPrivilegedAcceptance.v2`, declare and pass exactly the shared sixteen-capability contract, report Release configuration, and prove Windows 10 22H2 x64 with an administrator token. Its capability, error, environment, workload, history, reconciliation, service, and result artifacts must exist and the errors artifact must be empty. The physical preflight must contain only `PASS` checks for Windows 10 22H2 x64. The installer artifact must be the real `storage-chronicle.installer-acceptance.v1` result for `Windows10-22H2`/`PhysicalMachine`/`Local` with all eleven case IDs and every individual case status passed. All three inputs must carry the same non-empty `ComputerName`, preventing accidental combination of evidence from different PCs. The script loads the shared `AcceptanceContracts.ps1` from the repository during development or from the bundle-local directory when run from a Windows 10 manual acceptance bundle. VirtualBox/guest evidence is neither required nor accepted.

Tests: PowerShell parser validation and the no-input fail-closed path are host-testable. A `PASSED` result requires real privileged and installer artifacts from the human-approved physical Windows 10 run; synthetic fixtures and diagnostic runs are not eligible.
