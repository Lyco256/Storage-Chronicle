# TestDataGenerator/Program.cs

Produces deterministic newline-delimited event metadata or a Golden JSON document with `--format ndjson|golden`, bounded by five million records and controlled by `--seed`. The fixture intentionally contains no file contents or content hashes. When `--output` is supplied, it rejects traversal, UNC/device, drive-relative, alternate-stream, and missing-parent paths, then pins every directory from the local fixed NTFS volume root through the output parent using handles that deny delete sharing. Each handle is checked for directory/reparse attributes and its final volume path is matched to the preceding handle. The final file is created as a direct child of the pinned parent handle with `NtCreateFile(FILE_CREATE)`, so directory rename, reparse substitution, drive-letter remapping, and existing-name replacement cannot redirect/truncate the output during the operation. Parent directories are never created. File output fails closed on non-Windows platforms; stdout remains available. The caller must still select an approved isolated evidence root.
