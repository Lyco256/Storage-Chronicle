# r00-process-explorer-correlation.json

Golden, metadata-only fixture for R-00 sections 8 and 9. It fixes three process attribution cases (`Exact`, `Correlated`, and `Unknown`) and four Explorer/create cases: one strict correlated paste, two uncorrelated Explorer creates, and one non-Explorer create excluded from the Explorer denominator.

The fixture records names, identifiers, paths, origins, qualities, process names, parent identifiers, Clipboard generations, and operation hints only. It contains no file contents or content hashes. Changes to the expected counts require top-agent review because they change recorded acceptance evidence.
