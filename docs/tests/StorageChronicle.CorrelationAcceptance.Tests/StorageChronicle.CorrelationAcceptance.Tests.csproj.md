# StorageChronicle.CorrelationAcceptance.Tests.csproj

Windows-targeted, non-privileged acceptance project for the deterministic R-00 sections 8–9 fixture. It references the existing Domain, Contracts, Agent pipeline, Normalization, Projection, Windows Session, and Session Agent assemblies without introducing a shared contract. The fixture is copied to the test output directory and the project is included in the solution so the normal build sees it.
