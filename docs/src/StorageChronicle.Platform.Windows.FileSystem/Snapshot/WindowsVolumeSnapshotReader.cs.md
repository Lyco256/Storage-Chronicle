# WindowsVolumeSnapshotReader

Performs directory-unit initial enumeration with bounded result batches. On real volume IDs it selects the direct volume-GUID root (not a mounted-folder alias), opens the root without following a final-component reparse point, reads its metadata from that bound handle, and enumerates children from the same handle. Each child is opened relative to its already-open parent handle using exactly one directory-entry name; metadata and parent identity are read from the resulting child handle and pinned parent handle. Only a non-reparse directory can enter the traversal stack, carrying that same open handle into recursion. Replacing any path ancestor after opening the root cannot redirect a descendant open; if an enumerated directory is replaced by a symlink before its relative open, the link itself is recorded and its target is not enumerated. Child-open/type errors and directory enumeration failures become explicit gap events. Result and gap batches are emitted at the configured limit without exceeding the bound. Access-denied metadata falls back to `ExistenceOnly`; exclusions are evaluated before metadata acquisition. Tests cover relative-handle ancestry, a Windows temporary-directory reparse swap at the enumeration/open boundary, reparse non-recursion, direct volume roots, access fallback, cancellation, FAT/exFAT-style quality, and no content access.
