# WindowsVolumeSnapshotReader

Performs directory-unit initial enumeration with bounded result batches. On real volume IDs it selects the direct volume-GUID root (not a mounted-folder alias), opens each traversed directory without following a final-component reparse point, reads the directory metadata from that bound handle, and enumerates children from the same handle. Child metadata opens also use final-component no-follow semantics; only a non-reparse directory can enter the traversal stack, and it is reopened and revalidated before recursion. A final-component replacement therefore fails closed as a continuity gap rather than following its target. A fake-native test exercises a queued-directory replacement and proves no target child is accepted; a Windows API test checks that a final directory symlink is rejected by the monitor. Ancestor components of child paths remain path-resolved, so a parent swap requires a future relative-handle native contract to close. Access-denied metadata falls back to `ExistenceOnly`; directory disappearance and enumeration I/O failures become gap events. Exclusions are evaluated before metadata acquisition. Tests cover reparse non-recursion, replacement, direct volume roots, access fallback, cancellation, FAT/exFAT-style quality, and no content access.
