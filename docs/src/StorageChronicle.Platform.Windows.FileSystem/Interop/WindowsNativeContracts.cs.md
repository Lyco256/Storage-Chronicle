# WindowsNativeContracts

Contains injectable, thin native boundaries for volume enumeration, metadata/file handles, handle-bound direct-child enumeration, ReadDirectoryChangesW, and Configuration Manager device notifications. `IWindowsFileMetadataNative` exposes both path metadata and metadata from an already-open handle; its directory enumeration accepts only an open directory handle. `NativeDirectoryEntry` carries only a direct child's name and standard attributes. The native implementation refuses final-component reparse directories before traversal. Full paths still resolve ancestor components, which this contract cannot anchor relative to the verified parent handle. The records contain standard metadata and identity only; no file contents or hashes are represented. Fakes in the Windows filesystem tests exercise path-replacement, cancellation, and failure behavior without privileged Win32 state.
