# WindowsNativeContracts

Contains injectable, thin native boundaries for volume enumeration, metadata/file handles, handle-bound direct-child enumeration, ReadDirectoryChangesW, and Configuration Manager device notifications. `IWindowsFileMetadataNative` exposes path metadata for non-traversal callers plus handle-bound and parent-relative metadata/open operations for snapshot traversal; directory enumeration accepts only an open directory handle. `NativeDirectoryEntry` carries only a direct child's name and standard attributes, and `OpenChild` accepts one component plus an already-open parent handle. The native implementation opens the final reparse object without following it and refuses reparse directories before traversal. Snapshot ancestry is anchored through the pinned handle chain rather than full path resolution. The records contain standard metadata and identity only; no file contents or hashes are represented. Fakes and Windows temporary-directory tests exercise relative-open ancestry, a reparse swap between enumeration and open, cancellation, and failure behavior without privileged Win32 state or physical media.
