## 目的

同一File System ProjectionからLive、Period Diff、Point in Time、ReplayをTreeまたはExplorer形式で表示する。

## Tree

- 固定左ガターに主操作、サブ操作、品質アイコン。
- 全行で縦整列。
- ガターの右にインデント、展開、ファイル種別、名前。
- 仮想化階層リスト。
- 削除済み仮想ツリー。
- 場所不明仮想ルート。
- 上位フォルダーの配下件数。
- 展開時に子を遅延取得。
- 色とアイコンを併用。

## Explorer

フォルダーツリーのサイドバーは作らない。

- 特大、大、中、小アイコン。
- 一覧。
- 詳細。
- 並べて表示。
- コンテンツ。
- アイコン連続ズーム。
- 全分割枠で表示方式共通。
- 戻る、進む、一つ上、パンくず、パス入力。
- 削除済み仮想フォルダーへ移動可能。
- diff背景、主アイコン、サブアイコン、品質表示。
- 現在存在する項目をOSのExplorerで開く。削除済み・場所不明では無効化し理由を表示。

## 分割枠

- 離れた変更位置ごと。
- 同じプロセスでも別位置は別枠。
- タイトルバーにプロセス、時間、継続、変更量、内訳、状態。
- 枠は開始順。
- 標準は新しいものが上。
- 昇順・降順。
- タイムアウトまたはプロセス終了で消える。
- 固定枠は残る。
- Replayで出現・更新・消滅を再現。
- Live表示の一時停止・再開。停止中もAgent記録は継続。
- Replayのタイムライン、現在へ戻る、1倍、2倍、10倍、イベント送り。
- 枠一覧は仮想化縦スクロール。

## 差分

- 製品要件の色優先。
- 作成後削除。
- 名前変更経路。
- 同一名別実体。
- 移動後編集。
- Share専用アイコン。
- Folder移動・削除を展開して時点子孫を表示。
- Move元・先を関連リンクまたは矢印操作で相互移動。

## テスト

Headlessで全表示方式、Treeガター、ナビゲーション、Explorerで開く可否、枠消滅、固定、Live一時停止、Replay速度・イベント送り、Move相互移動、削除済み、場所不明、大量ノード遅延生成。

## 受け入れ条件

- TreeとExplorerが同一Projectionを使う。
- 表示切替えで選択場所、時刻、フィルターを維持。
- OSファイルシステムをUIから直接読むコードがない。
- 全ノードを一括Control化しない。
